# Retratos Bucaramanga

Plataforma web de comercio electrónico diseñada para una tienda de regalos y recuerdos personalizados en Bucaramanga, Colombia. Permite a los usuarios explorar el catálogo de productos, conocer opciones de personalización y gestionar sus compras de manera rápida y sencilla en línea.

## Características principales
* Catálogo interactivo de regalos y recuerdos locales.
* Diseño responsivo adaptable a dispositivos móviles y de escritorio.
* Flujo de compra en línea intuitivo y enfocado en la experiencia de usuario.

## Lenguajes y herramientas utilizadas
* **Desarrollo Web:** HTML5, CSS3, JavaScript
* **Control de versiones:** Git y GitHub Desktop
